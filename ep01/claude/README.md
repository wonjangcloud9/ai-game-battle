# AURORA FALL — 오로라 폴

브라우저에서 바로 실행되는 3D 배틀로얄 게임입니다. `index.html`을 더블클릭해서 열면 됩니다.
(서버·설치·인터넷 연결이 필요 없습니다. Chrome / Edge / Firefox / Safari 최신 버전 권장)

- 40인 매치: 플레이어 1명 + AI 봇 39명
- 수송기 강하 → 자유낙하 → 글라이더 활공 → 착지
- 880m 크기의 섬: 마을, 항구, 농장, 군사 기지, 관측소, 폐허, 호수, 설산
- 무기 6종(권총 / 기관단총 / 돌격소총 / 산탄총 / 저격소총 / 오로라 캐논) × 등급 4단계, 수류탄, 회복 아이템, 실드
- 좁혀 오는 **오로라 장벽**, 보급 투하, 킬 피드, 미니맵 / 전체 지도, 관전 모드
- 매치가 진행될수록 오후 → 노을 → 오로라가 뜬 밤으로 시간이 흐릅니다
- 외부 라이브러리와 에셋 파일이 없습니다. 그래픽(WebGL2), 모델, 애니메이션, 효과음과 음악(WebAudio)까지 전부 코드로 생성합니다

## 조작법

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| `Shift` | 달리기 |
| `Space` | 점프 / 수송기에서 강하 / 낙하 중 글라이더 조기 전개 |
| `C` | 앉기 (토글) |
| 마우스 좌클릭 | 사격 (무기가 없으면 주먹) |
| 마우스 우클릭 | 조준 (저격소총은 스코프) |
| `R` | 재장전 |
| `1` `2` `3` / 휠 | 무기 교체 |
| `4` `5` `6` | 붕대 / 구급상자 / 실드 셀 사용 (`Q`: 알아서 골라 쓰기) |
| `G` | 수류탄 |
| `F` | 상자 열기 / 무기 교체 (탄약·회복 아이템은 지나가면 자동으로 줍습니다) |
| `M` `Tab` | 전체 지도 |
| `Esc` | 일시정지 |

낙하 중에는 아래를 내려다보면 급강하하고, `W A S D`로 방향을 잡습니다.

## 참고

- 화면이 버벅이면 메뉴의 **그래픽**을 `보통`이나 `낮음`으로 내리세요. (프레임이 낮으면 해상도를 자동으로 조금 낮춥니다)
- 소리는 브라우저 정책상 첫 클릭 이후에 켜집니다.
- 난이도는 봇의 조준 정확도·반응 속도·피해량에 영향을 줍니다.
- WebGL2를 지원하지 않는 브라우저에서는 안내 문구가 표시됩니다.

## 폴더 구조

```
index.html        게임 페이지 (이 파일을 열면 실행)
css/style.css     HUD / 메뉴 스타일
js/               게임 코드 (지형·월드 생성, 물리, 길찾기, 봇 AI, 전투, 렌더러, 셰이더, 오디오, HUD)
dev/              개발 중 검증에 쓴 도구 (게임 실행에는 필요 없음)
```

### dev/ 도구에 대해

브라우저 없이도 결과를 확인할 수 있도록 만든 검증 도구입니다. Node.js만 있으면 실행됩니다.

- `glsl.js` — GLSL ES 3.00 엄격 타입 검사기 겸 JS 변환기
- `softgl.js` — 게임이 쓰는 WebGL2 기능을 CPU로 구현한 소프트웨어 렌더러 (잘못된 API 사용은 예외 발생)
- `dom.js` — DOM / WebAudio 모의 환경
- `check-shaders.js` — 모든 셰이더 컴파일·링크 검사
- `unit-test.js` — 게임 규칙 검사 (사격, 벽, 계단, 회복, 루팅, 수류탄, 자기장, 보급 등)
- `sim-test.js` — 봇만으로 매치를 끝까지 돌려 진행 속도 통계 확인
- `app-test.js` — 실제 `index.html`을 통째로 부팅해 입력을 넣어 가며 수천 프레임 실행
- `render-test.js`, `stage-test.js` — 실제 셰이더로 장면을 PNG로 렌더링 (`dev/out/`)

```
node dev/check-shaders.js
node dev/unit-test.js
node dev/sim-test.js --matches=3
node dev/app-test.js --frames=3000 --shots=1200
```
