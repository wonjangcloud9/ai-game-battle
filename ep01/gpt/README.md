# LAST LIGHT — OUTPOST 09

설치와 인터넷 연결 없이 실행되는 1인칭 3D 배틀로얄 게임입니다.

## 실행

이 폴더의 **index.html**을 Chrome, Edge 또는 Safari에서 열고 **전장에 진입**을 누르세요. `vendor` 폴더, `game.js`, `style.css`를 함께 보관해 주세요. 웹 서버, npm 설치, 빌드가 필요하지 않습니다. WebGL 2를 지원하는 데스크톱 브라우저와 키보드·마우스를 사용하세요.

## 조작

| 키 | 동작 |
| --- | --- |
| W / A / S / D | 이동 |
| 마우스 | 시점 회전 |
| 마우스 왼쪽 버튼 | 사격 (길게 누르면 연사) |
| 마우스 오른쪽 버튼 | 조준 |
| Shift | 달리기 (스태미나 소모) |
| Space | 점프 |
| 1 / 2 | 소총 / 산탄총 교체 |
| R | 재장전 |
| E | 근처 보급품 획득 |
| F | 구급 키트 사용 |
| M | 전술 지도 |
| Esc | 일시정지 / 재개 |
| 방향키 | 보조 시점 회전 |

브라우저가 마우스 잠금을 허용하지 않으면 마우스 드래그 또는 방향키로 시점을 움직일 수 있습니다. 일시정지 메뉴에서 마우스 감도와 소리를 조절할 수 있습니다.

## 게임 규칙

- 플레이어 1명과 AI 봇 15명이 참가합니다. 봇들은 서로 싸우고, 엄폐물을 이용하며, 안전 구역으로 이동합니다.
- 마지막 생존자가 승리합니다. 로비에서 루키 / 솔저 / 베테랑 난이도를 선택할 수 있습니다.
- 안전 구역은 약 4분 동안 5차례 줄어듭니다. 파란 경계 밖에서는 지속적으로 피해를 받습니다. 지도 점선은 다음 안전 구역입니다.
- 소총은 중거리 연사에, 산탄총은 근접전에 적합합니다. 머리를 맞히면 추가 피해를 줍니다.
- 노란 보급품은 탄약, 파란 보급품은 보호막, 연두 보급품은 구급 키트입니다. 처치된 봇도 보급품을 남깁니다.
- 구급 키트는 2.3초 후 체력 65와 보호막 35를 회복합니다. 회복 중 사격하거나 피해를 받으면 취소됩니다.
- Esc, 다른 창으로 전환 또는 브라우저 탭을 숨기면 전투가 일시정지됩니다.
- 승리 횟수와 최고 처치 기록은 브라우저의 로컬 저장소에 저장됩니다. 외부로 전송되는 데이터는 없습니다.

## 파일

- `index.html`: 로비, HUD, 메뉴
- `style.css`: 화면 스타일
- `game.js`: 3D 월드, 봇, 전투, 음향, 게임 진행
- `vendor/three.min.js`: 로컬 번들 Three.js r180
- `vendor/THREE-LICENSE.txt`: Three.js MIT 라이선스

지형, 건물, 캐릭터, 무기, 아이템은 코드로 생성합니다. 사운드는 Web Audio로 합성하며 외부 이미지, 폰트, 서버 또는 CDN을 사용하지 않습니다.

## 로직 검증

Node.js가 있는 개발 환경에서는 `node tests/smoke.cjs`로 실제 게임 코드의 통합 테스트를 실행할 수 있습니다. 실행 자체에는 Node.js가 필요하지 않습니다. 테스트는 사격, 엄폐, 이동, 회복, 보급, AI 전투, 안전 구역, 일시정지, 승패 및 재시작을 검증합니다. WebGL 출력과 브라우저의 마우스 잠금은 이 테스트의 검증 범위에 포함되지 않습니다.
