# DUNE DRIFT

석양의 사막 서킷에서 펼쳐지는 3D 카트 레이싱 게임입니다. AI 카트 3대와 3랩을 달립니다.

**`index.html`을 브라우저로 열면 바로 실행됩니다.** 설치, 빌드, 로컬 서버, 인터넷 연결이 필요하지 않습니다. `index.html`, `style.css`, `engine.js`, `game.js`를 같은 폴더에 두세요.

| 조작 | 키 |
| --- | --- |
| 가속 | W / ↑ |
| 브레이크 · 후진 | S / ↓ |
| 좌우 조향 | A D / ← → |
| 드리프트 | 가속 중 Space + 좌우 방향키 |
| 부스터 | 가속 중 Shift 길게 누르기 |
| 트랙으로 복귀 | R |
| 일시 정지 · 계속 | Esc / P |
| 소리 켜기 · 끄기 | M |

드리프트를 유지하면 부스터 게이지가 찹니다. Space를 놓은 뒤 Shift를 누르면 충전량을 소모하며 가속합니다. 충분히 긴 드리프트 뒤에는 짧은 미니 터보도 발동합니다. 도로 밖의 모래에서는 속도가 줄어듭니다. 코너에 진입하기 전에 속도를 줄이고 드리프트를 시작해 보세요.

터치 기기에서는 화면의 방향, GO, BRAKE, DRIFT, BOOST 버튼을 사용합니다. 개인 최고 기록은 브라우저가 허용하는 경우 로컬에 저장됩니다. 창을 전환하면 레이스가 자동으로 일시 정지됩니다.

WebGL을 지원하는 최신 Chrome, Edge, Firefox, Safari에서 플레이할 수 있습니다. 그래픽이 표시되지 않으면 브라우저의 하드웨어 가속 설정을 확인하세요.

게임, 3D 모델, 서킷, 효과음은 모두 폴더 안의 코드로 생성됩니다. 외부 에셋이나 CDN을 사용하지 않습니다.
