# DEVLOG

## 2026-11-14 · 마무리 점검 — 여러 판을 돌려 보며 버그 · 성능 · 밸런스

실제 브라우저 엔진(WebKit)에서 서른한 판을 처음부터 엔딩까지 돌렸다(네 판은 진짜 시간으로. `tools/wk/play.js`). 자세한 표와 수치는 README 의 "오늘 바뀐 것".

**버그** — 손글씨 글꼴이 없는 브라우저(사파리 · 윈도우)에서 서로 덮고 잘리던 칠판 글씨, 좌석 배치도를 가로지르던 벽 몰딩, 표지를 넘긴 뒤에도 문항 위에 남던 본령 글씨, 빼앗긴 안경을 두고 뜨던 "다시 켤 수 있다"와 배터리 표시, 낱말 중간에서 바뀌던 줄, 판 내내 다시 뜨던 조작 안내, 좁은 창에서 화면 밖으로 잘리던 답안지, 빨리 감는 동안 여덟 배로 잦던 발소리.

**성능** — 깊이 먼저 그리기: 가려진 조각의 조명 계산을 없앴다(조명 계산 조각 수가 화면 픽셀의 2.05배 → 0.96배, 화면은 열아홉 장면에서 픽셀 단위로 같음. 득이 없는 애플 GPU 에서는 스스로 끈다). 느린 기기에서 해상도를 낮추는 장치는 세 단계까지 내려가 보고 1초마다 판단한다. 일시정지 중에는 그리기를 쉰다.

**밸런스 · 템포** — 일시정지 중에는 화면을 가린다(멈춰 놓고 문제지·렌즈의 답을 읽을 수 있었다). 시험 전의 기다리는 시간은 내 차례가 아닐 때 `T` 로 빨리 보낼 수 있다: 처음 하는 한 판은 그대로 8분 안팎, 여러 판째는 3분 안쪽(2분 52초). 시험 중 난이도는 그대로(가상 플레이어 적발 30 · 29 · 15 · 0 / 30).

**확인** — 자동 플레이 28종(오늘 고친 것의 회귀 시험 `polish` 포함) · 스트레스 40판 · 정적 점검 · ANGLE 재생 통과, 실제 엔진 시나리오 오류 0건. **못 한 것**: Chrome·Firefox 실행, 실제 포인터 잠금, 소리를 귀로 듣는 확인, 느린 그래픽 장치에서의 실제 프레임 시간(깊이 먼저 그리기의 득은 조각 수로만 확인했다. 이 기기는 타일 방식 GPU 라 켜면 프레임당 0.2~0.5ms 늘 뿐이어서 꺼 둔다). 작업 후반에는 기기가 다른 작업으로 바빠 프레임 시간 측정이 흔들렸다.

## 2026-11-14 · 엔딩 열 가지 · 처음 하는 사람을 위한 조작 안내 · 한 판 10분 안쪽

**엔딩**(`js/endings.js`) — 한 판이 열 가지 가운데 하나로 끝난다: 내 힘으로 합격 · 떳떳한 불합격 · 시험 중 적발·퇴실 · 합격, 그리고 취소(나중에 들킴) · 렌즈를 믿은 불합격 · 반칙하고도 불합격 · 들키지 않은 합격 · 시작도 전에 압수 · 켜지 않은 안경 · 안경도 없이 퇴실. 종료령 뒤에 에필로그(합격자 조회 → 그 뒤의 일 → 통지서)가 붙고, 엔딩 화면에 번호·이야기·남긴 흔적·본 엔딩 모음이 나온다.
'나중에 들킴'은 시험장에 남긴 흔적 4점부터(렌즈의 오답을 그대로 적은 문항 하나에 2점, 목격·경보·검사 2점, 스친 눈길 1점). 조건 표는 README.

**조작 안내**(`js/coach.js`) — 필요한 순간에 하나씩 뜨고, 해 보면 사라지고, 다음 판부터는 안 뜬다: 둘러보기 → 걷기 → 렌즈 끄고 켜기 → 고개 → 표지 넘기기 → 답 표기 → 문항 넘기기 → 렌즈로 답 띄우기. 본령 뒤의 표지는 이제 내 손으로 넘긴다(`D`). 켜진 렌즈는 복도에서 내 자리를 가리켜 준다.

**한 판 길이** — 바로바로 하면 8분쯤, 아무것도 안 눌러도 9분 27초, 가장 오래 끌어도 9분 33초(`node tools/timeline.js`, 시드 셋). 자리를 75초 안에 못 찾으면 감독관이 데려다 앉히고, 에필로그는 가만히 두어도 넘어간다.

**확인** — 자동 플레이 27종(새로 8종)·스트레스 60판·정적 점검 통과, 시험 중 난이도는 그대로(가상 플레이어 적발 30·29·15·0/30). 사파리 엔진에서 처음부터 엔딩 화면까지 돌려 화면을 눈으로 확인(오류 0건). 따로 맡긴 코드 검토에서 나온 여섯 가지(종 직후의 `D`가 꾸중을 듣던 것, 휠 한 번에 여러 장, 표지 앞에서 렌즈가 먼저 꺼지던 것, 손을 쓸 수 없을 때 뜨던 안내 등)를 고치고 회귀 시험을 붙였다. **못 한 것**: Chrome·Firefox 실행, 실제 포인터 잠금, 소리를 귀로 듣는 확인.

## 2026-11-14 · AI 안경을 쓰는 순간을 더 현실적이고 다양하게

**조작** — "`F` 길게 = 스캔"이 없어졌다. `F` 는 안경다리를 톡 치는 동작(왼손이 얼굴 옆으로 올라간다)이고, 켜진 채로 문제지를 보고 있으면 안경이 스스로 문항 찾기 → 글자 읽기 → 답 생성을 거쳐 답을 띄운다(켜서 답까지 3~7초). 눈길이 오면 같은 `F` 로 급하게 끈다(화면에 안내가 깜빡인다). `T` 는 렌즈가 꺼져 있을 때만 된다.

**안경 기기**(`js/glasses.js`) — 켜는 데 0.9초·끄면 잔광, 배터리(판마다 58~70%, 한 문항에 3% 남짓), 발열(쉬지 않고 서너 문항이면 과열로 꺼짐), 켤 때와 답이 나올 때의 작은 진동. 답은 열 문항 중 셋이 틀리고 그중 둘은 신뢰도 90% 이상으로 자신 있게 틀린다(부정형 문제는 "않은"을 놓치고 읽은 문장이 렌즈에 보인다). 문제 은행 24문항에 근거 문장을 새로 썼다.

**들키는 길**(`js/notice.js`) — 렌즈 반사(감독관이 걸음을 멈추고 다시 본다. 1초쯤 안에 끄면 넘어간다), 안경다리를 만지는 손, 진동 소리(가까운 감독관이 듣는다), 옆자리 시선(쳐다본다 → 켜져 있으면 본다 → 두 번이면 손을 든다).

**검사** — 시험 전 전자기기 탐지기(미리 끔: 통과 / 울릴 때 급하게 끔: 넘어가지만 찍힘 / 켜 둠: 압수). 시험 중 의심 80%나 옆자리 신고로 안경을 벗겨 보는 검사 한 번(넘겨줄 때 켜져 있거나 뜨거우면 적발).

**의심 게이지·긴장** — 게이지에 눈금(55% 지켜봄 · 80% 검사)과 오른 까닭 꼬리표. 심박수와 쿵-쿵 소리, 긴장하면 먹먹해지는 교실 소리·떨리는 숨·떨리는 손. 안경 배터리·온도 표시.

**난이도** — 가상 플레이어 30판 적발: 마구 쓰기 30/30, 눈치 조금 28/30, 읽고 쓰기 18/30(전 16/30), 조심 0/30. '쓴 횟수만큼 의심이 남는다'는 규칙은 없애고 감독관이 실제로 본 만큼만 남게 했다.

**확인** — 자동 플레이 19종·무작위 스트레스 60판·정적 점검·ANGLE(GLSL ES 3.00) 재생 통과. 새 도구 `tools/webkit.py`로 사파리 엔진에서 `index.html`을 `file://`로 실제로 열어 시험 전 세 갈래와 시험 중 전 과정을 돌렸다(페이지 오류 0건, 60fps, 화면을 찍어 눈으로 확인). 소리는 같은 엔진의 오프라인 렌더링으로 크기를 재서 맞췄다(`tools/wk/audio.js`): 켜짐 진동은 옆자리 기침보다 6dB쯤 작고 교실 바탕 소리보다 10dB 크게, 심장 소리는 낮은 음을 못 내는 노트북 스피커에서도 들리게. **못 한 것**: 소리를 귀로 듣는 확인, Chrome·Firefox 실행, 실제 포인터 잠금(가짜 환경으로만 확인).

## 2026-11-14 · 고사장을 실제 한국 학교 교실처럼

**빛** — 형광등 9대(2등용, 관이 보임)와 창문을 넓은 면광원으로 계산해 창가는 밝고 복도 쪽은 어두워진다. 방 모서리·책상 밑 음영, 마루·책상·칠판·TV에 비치는 창과 형광등, 가끔 깜빡이는 형광등 한 대.

**교실** — 칠판에 분필 손글씨로 시험 시간표·유의사항·날짜, 테 두른 벽시계(초침이 째깍), 둥근 모서리 상판과 쇠 파이프 다리의 책걸상 20벌, 미닫이 창과 묶어 둔 커튼, 추락 방지 난간, 선풍기·스위치·화재 감지기·분리수거함. 창밖은 그림 한 장이 아니라 3D(운동장·나무·국기 게양대·아파트 단지·먼 산)라 고개를 움직이면 겹쳐 보이는 정도가 달라진다. 복도 창밖에는 맞은편 교사동.

**사람** — 수험생은 몸통·팔다리를 새로 빚고 팔을 어깨–팔꿈치–손목으로 풀어, 쓰기·답안지 칠하기·책장 넘기기·턱 괴기·시계 보기·한숨·기침(손으로 입을 가림)·목 돌리기를 스스로 한다. 얼굴에 손을 대는 자세는 사람마다 다른 숙인 정도를 따라간다. 본령이 울리면 다 같이 표지를 넘긴다. 감독관은 **두 명**: 정감독은 교탁 옆, 부감독은 뒷짐 지고 교실 뒤. 통로를 돌다 멈춰 책상을 들여다보고, 팔짱을 끼거나 손목시계를 본다. 신분 확인·배부도 둘이 줄을 나눠 한다.

**내 책상(1인칭)** — 두 손과 소매·팔·무릎이 보인다. 오른손은 컴퓨터용 사인펜(몸통 글씨, 금색 띠, 뒤에 꽂은 뚜껑)을 쥐고 칸을 칠하고, 왼손은 책장 끝을 집어 넘긴다(휘어지며 넘어가는 책장, 뒷면 비침). 답안지는 타이밍 마크·수험번호 표기란·감독 확인 도장·세로 타원 칸으로 다시 그렸고, 손목시계는 교실 시계와 같은 시각을 가리킨다. 신분증은 손으로 들어 보인다.

**소리** — 종은 "땡" 대신 방송 스피커 음색의 딩동댕동(복도에서도 울림). 수험생의 펜 사각거림·사인펜 마킹·책장·한숨·기침·헛기침·훌쩍임·의자 삐걱·펜 톡톡이 그 사람 자리에서 동작과 함께 난다. 정감독은 구두, 부감독은 실내화 소리. 형광등 험, 시계 째깍, 창밖 새·차, 복도 발소리. 전부 코드로 합성(파일 없음).

**부드러움** — 프레임당 스크립트 0.39ms·그리기 295회(전에는 0.25ms·177회). 기록한 프레임을 실제 그래픽 장치(Apple M4 Pro, 2560×1600, 4×MSAA)로 재생하면 프레임당 1.3~1.6ms(그중 1.2ms쯤은 재생 도구가 호출하는 데 드는 시간). 화면이 아주 크면 렌더 픽셀 수에 상한을 두고, 프레임이 밀리면 해상도를 한 단계씩 낮춘다(나아지지 않으면 되돌림). 시작 준비(텍스처·모델 만들기)는 Node에서 약 0.25초.

**난이도** — 감독관이 둘이 되어도 예전과 같도록 맞췄다(가상 플레이어 30판 적발률: 마구 쓰기 30/30, 눈치 조금 30/30, 읽고 쓰기 16/30 ← 전 13/30, 조심 0/30). 규칙 하나가 바뀌었다: 감독관이 다른 자리를 콕 집어 보고 있을 때는 그 근처가 아니면 '시선'으로 거의 치지 않는다.

**도구** — `tools/view.js`(원하는 각도에서 장면 찍기), `tools/perf.js` + `native.py bench`(프레임 비용), `tools/sounds.js`(한 판 동안 소리가 몇 번 나는지), `tools/geomtest.js`, `check.js`에 셰이더 점검 추가. `native.py replay es`는 기록한 WebGL 호출을 사파리에 들어 있는 ANGLE(OpenGL ES 3.0, WebGL 호환 모드)로 재생한다 — 셰이더를 고치지 않고 넘기므로 브라우저와 같은 GLSL ES 3.00 컴파일러를 거친다.

**확인한 방법과 못 한 것** — 이번 작업 환경에서는 브라우저를 띄울 수 없었다. 진행은 가짜 브라우저 환경의 자동 플레이 10종으로, 화면은 기록한 WebGL 호출을 ANGLE로 재생한 그림으로 확인했다(셰이더 컴파일·링크 통과, GL 오류 0, 예비용 단순 그래픽도 통과). 그래도 ① 실제 브라우저 창에서의 프레임 속도와 화면 위 UI, ② 소리가 실제로 어떻게 들리는지는 직접 확인하지 못했다. 기침·한숨은 합성음이라 녹음만큼 사실적이지는 않다.
