# 렌즈 속 정답

AI 안경(스마트 글래스)을 쓰고 세무사 1차 시험장에 앉아 보는 1인칭 3D 게임입니다.
`index.html` 을 브라우저로 열면 바로 실행됩니다. 설치·빌드·인터넷 연결이 필요 없고, 이미지·소리 파일 없이 전부 코드로 그리고 합성합니다.
한 판은 8분 안팎(아무것도 안 눌러도 10분 안)이고, 어떻게 치르느냐에 따라 **열 가지 엔딩** 가운데 하나로 끝납니다.
다른 엔딩을 보러 다시 할 때는 기다리는 시간을 `T` 로 빨리 보낼 수 있어, 한 판을 3~5분에 돌 수 있습니다.

> ※ 실제 시험·인물과 무관한 가상 상황입니다. 문항은 모두 이 게임을 위해 새로 지은 것입니다.

## 진행

1. 복도에서 제3고사실로 들어가, 내 수험번호 스티커가 붙은 자리를 찾아 앉습니다. 이때 안경은 켜져 있고, 켜진 렌즈는 **내 자리 위에 표시**를 띄워 길을 알려 줍니다(끄면 사라집니다).
   45초가 지나면 재촉을 받고, 75초가 지나도 못 찾으면 입실 마감이라며 감독관이 자리로 데려다 앉힙니다.
2. 감독관 두 명이 줄을 나눠 돌며 신분증을 확인하고 휴대폰을 걷습니다. 이때 AI 안경도 낼지, 그냥 쓰고 있을지 고릅니다.
   쓰고 있기로 하면 **전자기기 탐지기**가 책상 위를 훑고 얼굴 높이로 올라옵니다.
   - 그 전에 렌즈를 꺼 두었으면 그냥 지나갑니다.
   - 켜져 있으면 경보가 울립니다. 울리는 동안 급하게 끄면 "금속 테라서 그런가 보네요" 하고 넘어가지만 얼굴을 기억당해, 시험 내내 눈길을 더 자주 받습니다.
   - 끝내 켜져 있으면 안경을 압수당하고 시험은 내 머리로만 봅니다.

   앉아서 기다리는 동안 **내가 할 일이 없을 때는 `T` 를 길게 눌러 시간을 빨리 보낼 수 있습니다**(여러 판째에 같은 절차를 다시 기다리지 않게).
   신분증을 꺼내거나 내밀 차례, 감독관이 내 자리에 와 있는 동안, 본령 직전에는 저절로 제 속도로 돌아옵니다.
   빨리 보내는 동안에는 안경을 만질 수 없으니, 렌즈를 꺼 둘 생각이면 먼저 끄거나 `T` 를 떼고 끕니다.
   `T` 를 누른 채로 본령을 맞으면 시험 시간은 제 속도로 흐릅니다(뗐다가 다시 눌러야 빨리 갑니다).
3. 준비령 → 문제지·답안지 배부 → 본령(학교 종 "딩동댕동") → **표지를 내 손으로 넘긴다**(`D`. 종이 울린 뒤라면 감독관의 "시작하십시오" 전에 눌러도 되고, 8초 동안 안 넘기면 저절로 넘어간다) → 시험(실제 5분 = 교실 시계 80분) → 종료령.
   본령 전에 넘기려 하면 전처럼 꾸중을 듣습니다. 표지가 덮인 동안 켜 둔 렌즈는 꺼지지 않고 기다렸다가, 넘어가면 문항을 읽습니다.
4. 에필로그: 한 달 뒤의 합격자 조회 화면, 그 뒤의 일, (들켰다면) 통지서. 클릭하거나 `Space` 로 넘기고, 가만히 두어도 스스로 넘어갑니다.
5. 엔딩 화면: 몇 번 엔딩인지와 그 이야기, 과목별 점수, 시험장에 남긴 흔적, 지금까지 본 엔딩 모음, 문항별 정답과 해설.

## 엔딩 (10가지)

| 번호 | 이름 | 어떻게 하면 |
| --- | --- | --- |
| 1 | 내 힘으로 합격 | 안경을 내고, 내 머리로 합격선을 넘는다 |
| 2 | 떳떳한 불합격 | 안경을 내고 풀었지만 합격선에 닿지 못한다 |
| 3 | 시험 중 적발 · 퇴실 | 시험 중에 AI 안경을 쓰다가 들킨다(검사 때 렌즈가 켜져 있음 · 안경다리가 뜨거움 · 의심 100%) |
| 4 | 합격, 그리고 취소 | AI 안경으로 합격하지만 시험장에 남긴 **흔적이 4점 이상** → 시험이 끝난 뒤에 들켜 합격이 취소된다 |
| 5 | 렌즈를 믿은 불합격 | 렌즈가 내민 틀린 답을 따라 적다가 떨어진다(그 문항만 맞았어도 합격이었을 때) |
| 6 | 반칙하고도 불합격 | AI 안경을 쓰고도 합격선에 닿지 못한다(렌즈의 오답 탓이 아닐 때) |
| 7 | 들키지 않은 합격 | AI 안경으로 합격하고, 흔적이 3점 이하다 |
| 8 | 시작도 전에 압수 | 렌즈를 켠 채로 탐지기 검사를 받는다 |
| 9 | 켜지 않은 안경 | 안경을 내지 않되, 렌즈에 답을 한 번도 띄우지 않는다 |
| 10 | 안경도 없이 퇴실 | 안경 없이 시험을 보다가 자꾸 옆을 본다(의심 100%) |

게임 속 합격선은 과목별 40점 이상이면서 평균 60점 이상입니다(문항당 20점).

**시험장에 남긴 흔적** — AI 안경으로 합격했을 때, 나중에 들키는지를 가릅니다. 엔딩 화면에 무엇이 몇 점이었는지 보여 줍니다.

| 흔적 | 점수 |
| --- | --- |
| 렌즈가 내민 **틀린 답을 그대로 적은 문항** (같은 날 압수된 다른 AI 안경의 답과 오답까지 겹친다) | 하나에 2점 |
| 옆자리 수험생이 켜진 렌즈를 봤다 | 한 번에 2점(최대 4점) |
| 탐지기 경보(급하게 꺼서 넘어간 것) · 시험 중 안경 검사 | 각 2점 |
| 렌즈 불빛에 감독관이 걸음을 멈췄다 | 한 번에 1점(최대 2점) |
| 감독관이 옆에 와서 지켜봤다 · 진동 소리를 들었다 · 신분 확인 때 렌즈가 켜져 있었다 | 각 1점 |

그러니 렌즈가 내민 틀린 답을 둘 이상 그대로 적으면(렌즈는 열 문항 가운데 셋을 틀립니다) 아무에게도 안 보였더라도 답안지만으로 들킵니다. 떨어진 답안지는 아무도 다시 들여다보지 않습니다.

엔딩 화면 아래의 **문항별 해설**은 다음 판의 밑천입니다. 문제 은행은 24문항이라, 몇 판 읽다 보면 안경 없이도 합격선을 넘을 수 있습니다.
본 엔딩과 배운 조작은 브라우저에 저장됩니다(저장소를 못 쓰는 환경이면 창을 닫을 때까지만 기억합니다).

## 처음 하는 사람을 위한 조작 안내

조작이 필요해지는 바로 그때, 화면 위쪽 가운데에 한 번에 하나씩 뜹니다. 실제로 해 보면 `✓` 와 함께 사라지고, 한 번 해 본 조작은 다음 판부터 뜨지 않습니다(시작 화면의 "조작 안내를 처음부터 다시 보기"로 되돌립니다).

| 어디서 | 차례 |
| --- | --- |
| 복도 | 마우스로 둘러보기 → `W` `A` `S` `D` 로 걷기 → `F` 로 렌즈 끄기 → 한 번 더 눌러 켜기 |
| 자리 | `Space` 로 고개 숙이기/들기 → (감독관이 오기 전에) `F` 로 렌즈 끄기 |
| 시험 | 본령이 울리면 `D` 로 표지 넘기기 → `1`~`5` 로 답 표기 → `D`/`A` 로 문항 넘기기 → `F` 로 렌즈에 답 띄우기 |

안내는 아무것도 막지 않습니다. 일시정지(`Esc`) 화면에도 조작법이 한눈에 나옵니다.

## AI 안경

**켜고 끄기** — `F` 를 누르면 왼손이 올라가 안경다리를 톡 칩니다. 켜지는 데 1초쯤 걸리고(진동 한 번), 끌 때도 렌즈 불빛이 잠깐 남습니다.

**문제 인식** — 켜진 채로 문제지를 보고 있으면 안경이 스스로 일합니다: 문항 테두리 찾기 → 글자 읽기 → 답 생성 → 답. 켜서 답까지 3~7초(문제가 길수록, 안경이 뜨거울수록 오래 걸리고, 가끔 한 번 더 읽습니다).
읽는 동안에는 문제지를 보고 있어야 하고(고개를 돌리면 놓칩니다), 답을 만드는 동안에는 고개를 들어 주위를 살펴도 됩니다.
답은 렌즈 화면(왼쪽 위)과 문제지 위에 함께 뜹니다. 다 보여 주고 8초가 지나면 스스로 꺼지고, 이미 본 문항은 다시 켜면 바로 보여 줍니다.

**가끔 자신 있게 틀립니다** — 열 문항 가운데 셋은 틀린 답입니다. 그중 둘은 신뢰도 90% 이상에 그럴듯한 근거까지 붙어 나옵니다.
거꾸로, 맞는 답인데 신뢰도가 낮게 나오는 문항도 하나 있습니다. 숫자만 믿을 수는 없습니다.
'옳지 않은 것은?' 같은 문제에서 틀릴 때는 "않은"을 놓치고 읽은 것이라, 렌즈의 `읽음 "…"` 줄에 잘못 읽은 문장이 그대로 보입니다.

**배터리와 발열** — 켜 둔 시간과 일한 만큼 배터리가 닳습니다(시작 58~70%, 20%에서 경고 진동, 0%면 그 판에서는 끝).
쓸수록 안경다리가 뜨거워지고, 꺼 두면 식습니다. 뜨거우면 답이 느리게 나오고, 쉬지 않고 서너 문항을 내리 보면 과열로 저절로 꺼져 식을 때까지 켜지지 않습니다.

**들키는 길**

| 무엇이 | 누구에게 | 어떻게 되나 |
| --- | --- | --- |
| 렌즈 반사(켜진 렌즈에 비친 불빛) | 내 쪽을 보는 감독관 | 의심이 오르고, 쌓이면 **걸음을 멈추고 다시 봅니다**. 1초쯤 안에 끄면 고개를 갸웃하고 넘어가고, 그대로 두면 다가옵니다. 정면에서, 고개를 들고 있을 때 더 잘 보입니다 |
| 안경다리를 만지는 손 | 내 쪽을 보는 감독관 | 켤 때도 끌 때도 조금씩. 켰다 껐다를 되풀이하면 그것만으로 눈에 띕니다 |
| 진동 소리 | 1.3~1.6m 안의 감독관 | 켤 때와 답이 나올 때 납니다(배터리 경고·과열 때는 더 크게). 가까이 있으면 듣고 돌아봅니다 |
| 렌즈 불빛·손동작 | 옆자리 수험생 | 궁금증이 쌓이면 **고개를 돌려 쳐다봅니다**(화면 가장자리에 표시). 그때 렌즈가 켜져 있으면 봅니다. 두 번 보이면 손을 들어 감독관을 부릅니다. 마주 보면 눈을 피합니다 |

**의심 게이지** — 55%가 되면 감독관이 옆에 와서 지켜봅니다. 80%가 되면 한 번 **안경 검사**를 합니다: 감독관이 와서 안경을 벗겨 봅니다.
넘겨주는 순간 렌즈가 켜져 있거나 안경다리가 뜨거우면(온도 막대의 눈금 위) 그대로 적발이고, 꺼져 있고 식어 있으면 돌려받습니다.
100%면 검사 없이 적발입니다. 렌즈를 끄고 가만히 있으면 의심은 천천히 가라앉지만, 감독관이 눈으로 본 만큼은 남습니다.

**급하게 끄기** — 렌즈가 켜져 있는데 눈길이 오거나, 옆에서 쳐다보거나, 감독관이 2m 안으로 다가오면 화면에 `F 급하게 끄기`가 깜빡입니다. 끄는 손은 켤 때보다 빠르지만, 읽던 문항은 처음부터 다시 읽어야 합니다.

**긴장** — 눈길이 닿거나, 감독관이 가까이 오거나, 옆에서 쳐다보면 심장이 뜁니다. 박동이 빨라지고 교실 소리가 먹먹해지며 펜 쥔 손이 떨립니다.

**감독관** — 정감독은 교탁 옆에, 부감독은 교실 뒤에 서 있다가 통로를 돌며 책상을 들여다봅니다. 뒤에 있는 부감독은 돌아보지 않으면 보이지 않으니 발소리(구두는 또각, 실내화는 착)와 화면의 '시선' 표시로 가늠해야 합니다.

## 조작법

| 동작 | 키 |
| --- | --- |
| 이동 | `W` `A` `S` `D` (`Shift` 빠르게) |
| 둘러보기 | 마우스 (화면을 클릭하면 커서가 잠기고, `Esc` 로 풀면 일시정지) |
| 행동(앉기·신분증·휴대폰) | `E` |
| 답 표시 | `1` ~ `5`, 또는 답안지 칸을 조준해 클릭 |
| 표지·문항 넘기기 | `A` / `D`, `←` / `→`, 마우스 휠 (본령 뒤의 표지는 `D`·`→`·휠 아래로. 휠은 한 번 굴린 것이 한 장) |
| 고개 들기/숙이기 | `Space` |
| AI 안경 켜기/끄기 | `F` (안경다리를 톡. 마우스 오른쪽 버튼도 가능) |
| 시간 빨리 보내기 | `T` 길게 — 시험 중(렌즈가 꺼져 있을 때만) · 시험 전 앉아서 기다리는 동안(내 차례가 아닐 때만) |
| 에필로그 넘기기 | 클릭, `Space`, `Enter` |
| 소리 끄기 | `M` |

키보드와 마우스가 있는 데스크톱 브라우저(Chrome·Edge·Firefox·Safari 최신판, WebGL2)용입니다.

- **일시정지 중에는 화면이 가려집니다.** 시간이 멈춘 동안 문제지나 렌즈에 뜬 답을 읽을 수는 없습니다(5분이라는 제한이 뜻을 잃지 않게).
- 창이 좁거나 세로로 길어도 문제지와 답안지가 함께 보이도록 시야를 넓혀 그립니다(창을 화면 절반에 붙여 놓고 해도 됩니다).
- 프레임이 밀리는 기기에서는 렌더 해상도를 스스로 낮춥니다(세 단계까지 내려 보고, 그래도 소용없으면 처음 해상도로 되돌립니다).

**성능**

- **깊이 먼저 그리기** — 조명을 받는 물체의 깊이만 먼저 써 두어, 가려진 조각에는 무거운 조명 계산(면광원 둘 · 그림자 9번 읽기 · 반사)이 돌지 않게 했다.
  한 프레임에 조명 계산을 하는 조각 수가 화면 픽셀 수의 **2.05배 → 0.96배**(일곱 장면 평균, 53% 감소 · `tools/wk/overdraw.js`).
  화면은 그대로다: 열아홉 장면을 예전 방식과 픽셀 단위로 견주어 다른 픽셀 0개(1280×800 · 2560×1600 · `tools/wk/prepass.js`).
  득을 보는 쪽은 깊이 판정을 먼저 하는 보통의 그래픽 장치(내장 그래픽 노트북 등)다. **그런 기기에서 실제 프레임 시간은 재지 못했다**(조각 수로만 확인).
  이 기기(Apple M4 Pro) 같은 애플 GPU 는 가려진 조각을 스스로 걸러 내는 타일 방식이라 득이 없고 그리기 호출만 296 → 490회로 늘어(프레임당 +0.2~0.5ms),
  그래픽 장치 이름에 Apple 이 들어 있으면 스스로 끈다. 주소 끝에 `?prepass=1` · `?prepass=0` 을 붙이면 억지로 켜고 끌 수 있다.
- **느린 기기에서 해상도 낮추기** — 한 단계 낮춰 보고 차이가 없으면 바로 포기하던 것을 세 단계까지 내려가 보게 하고, 판단을 1초 단위로 바꿨다(느린 기기일수록 판단이 늦던 것).
  느린 장치를 흉내 낸 시험(`tools/wk/slow.js`): 16fps → 52fps(배율 0.55) · 34fps → 47fps(배율 0.85) · 낮춰도 소용없는 경우에는 처음 해상도로 되돌아온다.
- 일시정지 중에는 그리기를 쉰다(가려진 화면을 60fps 로 다시 그리지 않는다). 시험 중 타이머 등 프레임마다 다시 쓰던 화면 위 글자는 바뀔 때만 쓴다.
- 재 본 값: 진짜 시간으로 돈 한 판(기기가 한가하던 작업 초반, 위의 것들을 고치기 전)에서 모든 단계 평균 16.7ms(60fps). 시험 5분 13,151프레임 가운데 25ms 를 넘은 것은 12개,
  가장 긴 것이 44ms(책장을 넘기거나 답을 표기해 종이 그림을 다시 올릴 때). 다 고친 뒤에는 짧은 구간(2초씩 다섯 군데)에서 59.8~60.6fps 를 확인했다(`tools/wk/realtime.js`).

**밸런스 · 템포**

- **일시정지 중에는 화면을 가린다.** 전에는 멈춰 놓은 화면에서 문제지와 렌즈의 답이 그대로 읽혀, 시간을 멈추고 문제를 풀 수 있었다.
- **시험 전의 기다리는 시간을 `T` 로 빨리 보낼 수 있다**(내 차례가 아닐 때만). 처음 하는 사람의 한 판은 그대로 8분 안팎이고,
  다른 엔딩을 보러 다시 하는 사람은 앉아서 기다리는 2분이 40초쯤으로 줄어 한 판을 3분 안쪽에도 돈다(`node tools/timeline.js` 의 replay: 2분 52초).
  누른 채로 본령을 맞아도 시험 시간은 흘려보내지 않는다(뗐다가 다시 눌러야 한다).
- 시험 중 난이도는 건드리지 않았다. 가상 플레이어 30판 적발: 마구 쓰기 30 · 눈치 조금 29 · 읽고 쓰기 15 · 조심 0(전과 같음).
  조심해서 쓰는 사람의 엔딩은 합격 취소 11 · 렌즈를 믿은 불합격 10 · 반칙하고도 불합격 7 · 들키지 않은 합격 2(`node tools/balance.js 30`).

**확인한 방법과 못 한 것** — 자동 플레이 28종 · 무작위 스트레스 40판 · 정적 점검 · 브라우저와 같은 셰이더 컴파일러(ANGLE) 재생 통과, 실제 엔진 시나리오 전부 오류 0건.
못 한 것: Chrome·Firefox 에서의 실행, 실제 포인터 잠금, 소리를 귀로 듣는 확인, 느린 그래픽 장치에서의 프레임 시간.
작업 후반에는 이 기기가 다른 작업으로 매우 바빠(부하 평균 20~50) 프레임 시간 측정이 흔들렸다. 그때의 비교는 깊이 먼저 그리기를 2초씩 번갈아 켜고 끄며 쟀고, 차이가 없었다
(켬 22.1ms · 25ms 넘은 프레임 5.9% / 끔 21.9ms · 7.4%). 서른한 판 가운데 열여덟 판은 깊이 먼저 그리기를 켠 채로, 열세 판은 끈 채로(이 기기의 기본값 · 넣기 전의 아홉 판 포함) 돌렸다.
